# Aula 05 — Comparativo de distribuições Linux

[Aula anterior](../Aula-4/README.md) · [Índice da disciplina](../README.md) · [Próxima aula](../Aula-6/README.md)

Estudo comparativo de **Kali Linux, Lubuntu, Zorin OS, Linux Mint e Fedora**, reorganizado a partir do material desta pasta. As indicações são avaliações qualitativas do resumo original; não há resultados de testes, versões de distribuições ou configuração de hardware registrados para fundamentar um benchmark.

## Perfil de cada distribuição no material

| Distribuição | Foco descrito | Vantagens destacadas | Limitações destacadas |
|---|---|---|---|
| Kali Linux | Segurança, pentest, redes e forense | Ferramentas de segurança, comunidade e uso em auditoria | Exige conhecimento de Linux; não é apresentado como escolha principal para iniciantes, uso doméstico ou jogos |
| Lubuntu | Menor consumo de recursos, com base Ubuntu | Leveza, baixo uso de RAM e aproveitamento de máquinas antigas | Interface mais simples e menos recursos integrados |
| Zorin OS | Facilidade de uso e migração do Windows, com base Ubuntu | Interface amigável, adaptação e uso doméstico | Recursos variam entre versões; pode consumir mais que opções leves |
| Linux Mint | Uso diário, estabilidade e produtividade, com base Ubuntu no comparativo | Interface tradicional, aprendizado e equilíbrio de recursos | Não é a opção mais leve; algumas tecnologias podem chegar mais tarde |
| Fedora | Desenvolvimento e tecnologias recentes | Programação, comunidade, segurança e relação com o ecossistema Red Hat | Atualizações frequentes e possíveis ajustes conforme o hardware |

## Matriz qualitativa original

## Indicações por finalidade

| Finalidade | Indicação registrada no resumo |
|---|---|
| Segurança da informação e pentest | Kali Linux |
| Computador antigo e baixo consumo | Lubuntu |
| Primeiro contato e migração do Windows | Zorin OS |
| Estudos, tarefas diárias e produtividade | Linux Mint / Zorin OS |
| Programação e trabalho técnico | Fedora |
| Trabalho administrativo | Linux Mint |
| Jogos | Zorin OS / Linux Mint; Fedora também é mencionado para usuários mais experientes |

O próprio material ressalta que jogos dependem de hardware, drivers, compatibilidade e configuração. Sem medições no repositório, as indicações não permitem concluir qual distribuição terá maior desempenho em uma máquina específica.
