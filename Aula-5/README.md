# 🐧 Aula 05 — Comparativo de distribuições Linux

[← Aula 04](../Aula-4/README.md) · [Índice](../README.md) · [Aula 06 →](../Aula-6/README.md)

Comparação acadêmica de cinco distribuições GNU/Linux segundo perfis de uso, praticidade e características abordadas na disciplina.

## 📊 Distribuições estudadas

| Distribuição | Foco principal | Vantagem apresentada | Atenção |
|---|---|---|---|
| [Kali Linux](https://www.kali.org/) | Segurança, redes e análise forense | Ferramentas especializadas | Não é a escolha principal do material para uso doméstico |
| [Lubuntu](https://lubuntu.me/) | Computadores de recursos limitados | Baixo consumo e interface leve | Experiência mais simples |
| [Zorin OS](https://zorin.com/os/) | Migração a partir do Windows | Interface amigável | Recursos variam conforme a edição |
| [Linux Mint](https://linuxmint.com/) | Produtividade e uso diário | Estabilidade e familiaridade | Não é a alternativa mais leve |
| [Fedora](https://fedoraproject.org/) | Desenvolvimento e tecnologias recentes | Ecossistema voltado a trabalho técnico | Atualizações frequentes |

## 💡 Indicações por cenário do estudo

| Necessidade | Distribuição indicada no material |
|---|---|
| Ferramentas de segurança | Kali Linux |
| Hardware modesto | Lubuntu |
| Migração do Windows | Zorin OS |
| Primeiro contato com Linux | Linux Mint ou Zorin OS |
| Desenvolvimento e trabalho técnico | Fedora |
| Uso administrativo | Linux Mint |

O desempenho em jogos e aplicações depende de hardware, drivers e compatibilidade. Antes de instalar, consulte os requisitos e a documentação oficiais de cada distribuição.
