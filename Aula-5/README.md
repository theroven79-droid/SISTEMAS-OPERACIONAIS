# 🐧 Aula 05 — Comparação de distribuições Linux

[← Aula 04](../Aula-4/README.md) · [Índice da disciplina](../README.md) · [Aula 06 →](../Aula-6/README.md)

Esta aula compara cinco distribuições Linux de acordo com seus objetivos, características e possíveis cenários de utilização. A análise tem **finalidade acadêmica** e não substitui testes de desempenho ou verificações de compatibilidade.

## 📊 Distribuições estudadas

| Distribuição | Uso em destaque | Vantagem apresentada | Ponto de atenção |
|---|---|---|---|
| [Kali Linux](https://www.kali.org/) | Segurança da informação e análise de redes. | Ferramentas especializadas. | Não foi apresentada como opção principal para uso doméstico. |
| [Lubuntu](https://lubuntu.me/) | Computadores com recursos mais limitados. | Ambiente leve. | Interface e recursos integrados mais simples. |
| [Zorin OS](https://zorin.com/os/) | Adaptação de usuários acostumados ao Windows. | Interface acessível. | Recursos disponíveis podem variar conforme a edição. |
| [Linux Mint](https://linuxmint.com/) | Produtividade e atividades cotidianas. | Facilidade de uso e estabilidade. | Não é necessariamente a alternativa mais leve. |
| [Fedora](https://fedoraproject.org/) | Programação e uso de tecnologias recentes. | Ambiente favorável ao desenvolvimento. | Ciclo de atualizações frequente. |

## 💡 Exemplos de escolha por necessidade

| Necessidade | Distribuição destacada no estudo |
|---|---|
| Ferramentas para análise de segurança | Kali Linux |
| Equipamento com poucos recursos | Lubuntu |
| Adaptação ao Linux após utilizar Windows | Zorin OS |
| Atividades diárias e primeiro contato | Linux Mint ou Zorin OS |
| Programação e desenvolvimento | Fedora |

A escolha real de uma distribuição depende de fatores como hardware, drivers, requisitos dos programas, atualizações e preferências do usuário.
